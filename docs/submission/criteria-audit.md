# Проверка перед демонстрацией по официальному брифу

Дата: 21 ноября 2026. Проверка начата до подготовки пяти частей стратегии. Основания: код репозитория, журналы проверок, полный текст предоставленного организаторами брифа. Баллы жюри не предсказываются. Условные числа кейса не являются данными МегаФона.

## Обязательные результаты и свидетельства

| Требование | Что есть и как проверить | Граница |
|---|---|---|
| Постановка задачи | Инструкции `agent/instructions.md`, вопросы, план в `results/00-intake.md` | Первый ответ нуждался в исправлении ссылок на страницы и числовых порогов |
| Документы, таблицы, сайты | PDF/DOCX/TXT/MD; CSV/XLSX; разрешённый HTTP(S) с проверкой адресов. `verify-analysis.mjs` | PDF без текстового слоя не OCR; лимиты файлов указаны в README |
| Ссылки на существенные сведения | ID источника, покрытие чтения, исходный PDF, журнал API, проверяемый калькулятор | Модель может ошибиться в номере страницы; нужна сверка |
| Исследование от вопросов | План вопросов, способ получения свидетельств, неизвестные и условия пересмотра | Логов оператора и реальных интервью нет; план не выдаётся за исследование рынка |
| Три разных варианта и возражения | Статус-кво, дешёвый сигнал, новый кабинет; отдельно прекращение направления | Выбор пилота в демонстрации делает оператор прогона, не сам агент за заказчика |
| Продуктовая и коммуникационная стратегии | Пять частей, сценарии согласий, сообщение, канал, подтверждение обещаний | Эффект предлагаемой телеком-услуги не измерен на реальных клиентах |
| План проверки и вред | Семейная рандомизация, ITT, окно, мощность, CI, остановка инцидентов | Примеры 12%/9% и 600 групп из брифа не результаты |
| Продолжение после перерыва | Контрольные точки, хеши материалов, CLI resume, локальная ссылка дела | Публичный сайт сохраняет историю в браузере, без синхронизации устройств |
| Поддержка решения | Карточка решения, владельцы, триггеры; числовой монитор в отдельном процессе | На Vercel после закрытия вкладки фонового мониторинга нет |
| Прозрачность и экономичность | JSON: usage, timings, actions; отдельный журнал затрат | Цена API зависит от квоты; полная стоимость с трудом человека не измерена |

## Четыре критерия оценки

**Проработанность.** Архитектура предусматривает источники, проверку чисел, альтернативы и возражения. Новый бриф выявил недостаток: стандартное чтение длинного документа по фрагментам недостаточно для полной стратегии. Добавлены явное полное чтение до 60 000 символов и режим развёрнутого отчёта. Достоверность стратегии проверяется отдельно от успешного HTTP-ответа.

**Нейротехнологии.** Одна аналитическая LLM, отдельные ASR и TTS, детерминированные расчёты, чтение документов, сохранение состояния. Папка агента открывается в редакторе. MCP-сервер и сложная многоагентная система не заявляются: CLI и процессы уже решают поставленные задачи. Число компонентов не выдаётся за преимущество само по себе.

**Имплементация.** Есть самостоятельный запуск, CI на Windows/Linux, отделение ключей от исходников, контрольные точки и проверки повторов/конфликтов. Для нового полного режима добавлены проверки сохранности текста и отказа на превышение лимита. Голос уже подтверждён ручным ответом пользователя ранее; это не измерение точности на репрезентативном корпусе.

**Качество.** Доступна публичная демонстрация без ключа проверяющего. Пользователь может остановить ответ, выключить микрофон, исправить запрос, отправить материал. Бесплатный CPU даёт задержку; непрерывность и доступность внешних бесплатных сервисов не гарантируются. Производственная готовность SaaS не заявляется.

## Что исправляется в этой поставке

1. Полный охват всех 11 страниц вместо скрытого ограничения выбранными фрагментами.
2. Развёрнутый отчёт вместо принудительного сокращения любой стратегии до компактной карточки.
3. Отображение восстановленных сообщений без ID: раньше совпадение с пустым идентификатором голосового ответа скрывало текст.
4. Настоящие Markdown-таблицы в диалоге вместо строк с вертикальными чертами.
5. Отдельные исходные ответы, проверенные расчёты, редакторские исправления и окончательный документ. Это позволяет оценить помощь человека.

## Что остаётся ограничением

Нет доказанного улучшения продуктовых метрик на реальном операторе; нет реальных интервью; нет сплошного анализа всех кадров и звуковой дорожки MP4; нет безусловного распознавания любого формата; нет распределённого фонового сервиса, многопользовательского промышленного SLA и независимого замера экономии против аналитика. Эти пункты не маскируются перечнем возможностей. Дополнительные возможности организаторы разрешают выбирать, а не требуют все сразу.
