# Учебный кейс согласования закупок

Новая задача проверяет активацию компаний в сервисе внутренних заявок. Все числа, организации и реплики вымышлены. Материалы созданы для проверки системы и не описывают клиентов МегаФона.

## Материалы

- `brief.txt` задаёт цель, получателя, ограничения, доступные изменения и неизвестные данные.
- `cohorts.csv` и `cohorts.xlsx` содержат одинаковые исходные значения.
- `interviews.vtt` содержит синтетические реплики с таймкодами.
- `new-data.csv` содержит новый замер после учебного выбора руководителя.
- `cohorts.png` проверяет чтение таблицы с изображения.

## Запуск проверки

Запустите приложение по корневому README. Для проверенного текстового профиля настройте GigaChat. Локальные прогоны Qwen показали ошибки качества, зафиксированные в аналитическом отчёте.

```powershell
node agent/verify-analysis.mjs
node agent/verify-workflow.mjs
node examples/procurement/run.mjs
```

Сценарий отправляет настоящие запросы текущему провайдеру через веб-API. Затем сохраняет решение, восстанавливает дело отдельным процессом CLI и проверяет новые данные без передачи истории чата. Учебный выбор руководителя в скрипте явно помечен как симуляция. Проверки структуры и арифметики дополняются проверкой смысла по брифу.

После прогона откройте [дело в локальном сервисе](http://127.0.0.1:5175/cases/procurement-check). В каждом ответе можно раскрыть материалы и ход работы. В деле доступны исходные файлы и продолжение диалога.

Состояние и журнал лежат в `cases/procurement-check/`. Папка исключена из Git. В ней создаются `acceptance.json`, `after.json`, `review.json` и контрольные точки. Повторный запуск добавляет новые контрольные точки этого учебного дела.

## Речь и изображение

```powershell
node examples/procurement/verify-voice.mjs
node examples/procurement/verify-image.mjs
```

Для голоса должны работать сервисы распознавания и синтеза. Тест преобразует синтетическую запись в монофонический WAV 16 кГц, который принимает распознаватель. По умолчанию используется Python из `D:/AI/qwen-voice/Scripts/python.exe`; для другого окружения задайте `CONTOUR_VOICE_PYTHON`. В окружении нужны NumPy и SoundFile.

Запись синтезированной речи проверяет серверную цепочку. Проверка микрофона, проигрывания в браузере и естественности голоса требует человека. Проверка изображения использует выбранный профиль модели. GigaChat принимает временный файл через собственный API.

## Что должно получиться

Первый замер — 48/120 = 40%, второй — 45/150 = 30%. Изменение составляет −10 процентных пунктов. Разные каналы привлечения не позволяют считать эту разницу эффектом изменения продукта.

После учебного выбора пилота новый замер 28/100 = 28% пересекает сохранённый порог «ниже 30%». Система показывает затронутое основание и предлагает отложить масштабирование до проверки сопоставимых данных.
