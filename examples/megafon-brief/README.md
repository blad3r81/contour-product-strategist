# Официальный демонстрационный проект

Кейс организаторов: «Связь для близких и собственных устройств». Вымышленный оператор, только учебные исходные данные. Дата прогона 21 ноября 2026.

## Что читать

- **[Итоговая стратегия из пяти частей](strategy.md)**: клиент, предложение и коммуникация, польза и прибыль, план, ресурсы. Это проверенная редакция после работы агента, не дословный ответ без помощи.
- [Исходный PDF](materials/official-brief.pdf), [извлечённый полный текст](materials/official-brief.txt). Все 11 страниц,29458 символов текстового слоя.
- [Расчёты и сценарные допущения](materials/calculations.md), [машиночитаемые значения](materials/calculations.json), [исполняемый калькулятор](calculate.mjs).
- [Что исправлено при проверке](review.md): ошибки не скрыты и не удалены из исходных ответов.
- [Таблица показателей](materials/targets.csv) переписана со страницы 3 брифа. `node examples/megafon-brief/chart.mjs` проверяет построение графика 62,5% и 66,67%; цель не выдаётся за результат эксперимента.
- [Запросы](prompts/) и [фактические ответы JSON/Markdown](results/). [Сводка времени, токенов и покрытия](run-summary.json).
- Готовые PDF в корневой папке `output/pdf/`; читаемая веб-версия - https://decision-contour.vercel.app/submission/official-strategy.html .

## Как воспроизвести

1. Выполните установку и настройку самостоятельного запуска из корневого README. Ключ берётся из внешнего файла или переменной, не из Git. Выберите GigaChat с доступной квотой; не выдавайте локальную подстановку за эту же модель.
2. Запустите `pnpm build`, затем `pnpm start`. По умолчанию сервер 127.0.0.1:5176. Укажите `CONTOUR_DEMO_URL=http://127.0.0.1:5176` для скрипта прогона, либо запустите сервер на PORT5180.
3. `node examples/megafon-brief/calculate.mjs` создаёт проверяемые расчёты. Прочитайте их: кроме чисел брифа там есть отдельный условный сценарий.
4. Поочерёдно вызовите `node examples/megafon-brief/run.mjs 00-intake`, затем 01-client,02-offer,03-benefit,04-roadmap,05-resources. Читайте ответы перед следующим существенным решением. Учебный семейный выбор явно указан в промптах оператором прогона.
5. Для 06-review скрипт прикрепляет `materials/strategy-for-review.md` под именем `strategy.md`: это текст стратегии для проверки без добавленных позднее скриншотов и их пояснений. Так сохраняется область исходной рецензии и не превышается лимит полного чтения. Это оценка подготовленного документа, не утверждение, что редакция возникла автоматически.
6. Остановите сервер. Выполните `node agent/cli.mjs resume official-megafon-brief`. Запустите сервер заново и `node examples/megafon-brief/run.mjs 07-resume`: запрос без history проверяет пересмотр при изменённом учебном темпе набора. Сам PDF и расчёты перечитываются, состояние решения сохраняется.
7. `node examples/megafon-brief/summarize.mjs` строит сводку по сохранённым ответам. Перед повтором сделайте копию results, чтобы не потерять опубликованный журнал; скрипт использует устойчивые имена шагов.

Локальный просмотр сохранённого диалога: `/cases/official-megafon-brief`. Папка cases не публикуется и не подмешивается в историю жюри. Для запуска нового независимого испытания измените caseId в копии скрипта; не используйте результаты старой проверки как новые наблюдения.

## Что показал прогон

Агент смог прочитать весь бриф, подготовить развёрнутые разделы, использовать вычисленный размер выборки и продолжить после паузы. Калькулятор подтверждает: цель 285 против 279 млн требует 6 млн;1600 номеромесяцев дают 800 тыс., после 300 тыс. расходов вклад 500 тыс.; при условных 12%/9% нужно 1638 семей на плечо. При 20 семьях/неделю 3276 семей набираются 164 недели плюс наблюдение.

Одновременно обнаружены ошибки: вымышленные пороги, неверные единицы, номер страницы, сроки, обращения с пропусками. Рецензия той же модели не всегда находила их корректно. Поэтому результат дополнен проверкой и редактурой с Codex, а не объявлен идеальным. Вариант запроса провайдер заблокировал; сохранённый отказ находится рядом с успешными ответами. Фильтрация не отключалась.

Спрос, эффект, цены, логи биллинга и реальные интервью неизвестны. Условный базовый прогноз 279,5 млн оставляет 5,5 млн доцели. Этот разрыв намеренно сохранён. Сценарий делает полезным решение «продолжить исследование / изменить / остановить», а не только обещание роста.
